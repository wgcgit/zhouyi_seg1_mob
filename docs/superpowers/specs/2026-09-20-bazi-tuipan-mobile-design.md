# 八字推盘移动端适配项目设计文档

## 1. 项目概述

**项目名称**: 周易之易 - 移动端版本
**项目类型**: 移动端Web应用适配
**核心功能**: 保留原PC端全部功能，针对移动端视口和交互习惯进行界面改造
**目标用户**: 手机用户，随时随地进行命理查询和分析

## 2. 技术方案

### 2.1 技术选型
- **前端**: 原生 HTML/CSS/JavaScript + Tailwind CSS（沿用现有技术栈）
- **后端**: 复用原项目 `zhouyi_seg1/backend/`，接口不变
- **部署**: 完全独立部署，与PC端互不依赖

### 2.2 项目结构
```
zhouyi_seg1_mob/
├── backend/                    # 直接复用原项目后端
│   ├── server.js
│   ├── routes/paipan.js
│   ├── LunarCalendar.js
│   └── ...
├── frontend/                   # 移动端专属前端
│   ├── index.html             # 信息录入页
│   ├── result.html            # 结果展示页
│   └── shared/
│       └── cities.js          # 城市数据
└── docs/
    └── superpowers/specs/     # 设计文档
```

## 3. 页面结构

### 3.1 信息录入页 (index.html)

#### 顶部导航
- 简洁顶部栏：仅包含Logo标题和必要操作按钮
- 无PC端的左侧边栏和复杂导航

#### 表单布局
- 姓名输入框（最多10字）
- 性别选择（男/女切换按钮）
- 出生时间（日期 + 时间选择器）
- 出生地点（省市二级联动下拉）
- 高级分析开关

#### 移动端优化
- 所有表单项纵向堆叠
- 底部固定"开始排盘"按钮
- 输入框高度加大，便于触摸操作
- 省市下拉框全宽展示

### 3.2 结果展示页 (result.html)

## 4. 设计规范

### 4.1 布局规范
- **视口**: 移动端优先，适配 375px - 428px 宽度
- **安全区域**: 顶部和底部留出安全距离，避免刘海/圆角遮挡
- **内边距**: 左右 20px
- **间距系统**: 沿用原项目 8px 基础单位

### 4.2 颜色系统（沿用原项目）
| 用途 | 颜色代码 |
|------|----------|
| 主色 | #715b3e |
| 背景色 | #fff8f5 |
| 卡片背景 | #ffffff |
| 文字主色 | #1e1b18 |
| 文字辅助色 | #4d453c |
| 边框色 | #d1c4b9 |

### 4.3 字体系统（沿用原项目）
- **标题**: Source Serif 4
- **正文**: Manrope
- **标签**: Be Vietnam Pro

### 4.4 圆角与阴影
- **卡片圆角**: 12px
- **按钮圆角**: 12px（主要）/ 全圆角（小型按钮）
- **阴影**: `0px 4px 20px rgba(139, 115, 85, 0.08)`

### 4.5 交互规范
- 触摸目标最小 44px × 44px
- 按钮点击有视觉反馈（透明度变化）
- Tab切换平滑过渡
- 卡片展开收起动画 300ms

## 6. 关键设计决策

### 6.1 顶部Tab vs 底部Tab
选择顶部Tab导航，与PC端左侧导航对应，便于用户理解功能模块一致性。

### 6.2 纵向四柱 vs 横向四柱
选择纵向堆叠展示，适配移动端窄屏，避免横向滚动带来的体验问题。

### 6.3 完全独立 vs 共用资源
选择完全独立部署，确保移动端和PC端互不干扰，便于独立迭代和维护。
