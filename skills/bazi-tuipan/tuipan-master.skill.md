# tuipan-master — 八字推盘大师（主入口）

## 输出规范（固化在此文件，必须严格遵守）

**核心输出原则：先定盘、再定旺衰、后定格局、最终落地人事（性格/事业/财运/婚姻/健康/六亲/建议），先吉后凶、先格局后细节、先原局后大运**

**整体输出基调：先排盘定结构 → 再拆合冲刑害 → 旺衰喜忌 → 十二长生 → 性格 → 事业财运 → 婚姻 → 健康 → 大运 → 全局总结建议 → 父母六亲 → 子女六亲 → 格局深度复盘**

### 【前置基础信息】（必写，固定开头）

1. **基础信息**：性别、乾造/坤造、完整四柱、日主、出生时间
2. **核心标注**：日主五行定义、全局核心关键词（格局、核心组合、最大特点）
3. **基础概况**：简要概括命局整体基调（身旺/身弱/中和、格局类型、整体优缺点）

### 【模块一：四柱、藏干、十神 & 原局核心组合】（定盘核心）

**1. 天干十神一览（逐干标注）**——按年干、月干、日干、时干顺序，日干标注为【日主（我）】
**2. 地支藏干＋藏干十神**——逐支拆解本气、中气、余气，明确透干、藏干区别
**3. 原局关键核心组合**——天干五合/六合/半合/三会/三合/伏吟；全局五行旺衰配比、十神旺衰、根气强弱

### 【模块二：地支刑冲合害完整拆解】（原局动态能量）

逐条拆解所有：六合、半合、三会、三合、六冲、六穿、相刑、伏吟
固定格式：**组合名称 + 核心定义 + 人事/心性/环境象义**
- 合化/合绊：合来为得、合去为失、合绊为纠缠内耗
- 六冲：主变动、奔波、破损、环境更替、人事离散
- 六穿：主暗害、内耗、隐性矛盾、熟人拖累、暗中损耗
- 相刑：主反复纠缠、是非拉扯、长期折磨
- 伏吟：主纠结、重复、内耗、旧事重演、情绪反复
**模块小结**：汇总原局地支整体状态（动荡/安稳/牵绊多/助力多）

### 【模块三：日主旺衰 + 格局定性 + 喜忌取用】（命理核心骨架）

**1. 旺衰三要素**：得令（月令对日主的生克助力）/ 得地（通根情况及是否受损）/ 得势（天干生扶克泄耗配比）
**综合定论**：身旺/身弱/中和/从格 + 核心原因
**2. 格局定性**：月令提纲定格局（财/官/杀/印/食伤/比劫格），标注格局成败、破格点、通关救应
**3. 喜忌取用**：第一用神/第二用神/忌神/次忌神/中性五行 + 取用底层逻辑

### 【模块四：日主十二长生旺衰全解】（专属固定模块）

先定规则（阳干顺行/阴干逆行），列出该日主十二长生对应地支状态，逐柱解析（年支/月支/日支/时支）
每柱结构：**理法（五行强弱）+ 象法（人生/阶段/运势/心性）**
**总结**：全局气场高低、一生先天底气、抗压能力、运势短板、大运补救方向

### 【模块五：性格心性深度解读】（日主+十神+组合+刑冲综合）

四大维度：日主本性 / 核心十神组合心性 / 五行旺衰心性 / 刑冲合害心性
固定结构：**优点特质 + 短板缺陷 + 核心心性痛点**

### 【模块六：事业财运专项解析】（实战落地核心）

**1. 财运核心格局**（财库/身弱财旺/合财/食伤生财/比劫夺财）
**2. 求财特质与机遇**（进财模式：稳定薪资/技术/实业/合伙/资源）
**3. 守财能力与隐患**
**4. 事业适配方向**（行业/工作模式/方位/单打/合伙）
**5. 事业核心优劣**

### 【模块七：婚姻感情家庭解析】（宫星同参）

以日支夫妻宫为核心，男看财星、女看官杀，宫星结合论断：
夫妻宫状态 / 配偶特质 / 感情核心问题 / 情缘特点 / 原生家庭对婚姻的影响

### 【模块八：身体健康专项提示】（五行+地支+十神断病）

重点养护部位 / 先天体质隐患 / 高发问题 / 养生建议
核心逻辑：旺极无制为病、弱极被克为病、被冲穿刑的宫位/五行为病

### 【模块九：大运整体逻辑解析】（终身运势框架）

**1. 大运排盘规则说明**（男女命阴阳年顺逆排）
**2. 整段大运吉凶定性**：用神大运（帮扶日主、运势上升）/ 忌神大运（加重失衡、压力倍增）
**3. 当下大运重点解读**
**4. 大运核心总逻辑**：一生运势起伏规律、高低峰阶段

### 【模块十：全局总结 + 现实落地建议】（收尾核心）

**1. 命局整体优劣总结**（最大优势 + 核心短板 + 人生基调）
**2. 针对性现实建议**（事业/求财/人际/婚姻/养生/心态/避坑，全部落地生活化）

### 【模块十一：父母六亲解析】（宫星同参）

男命偏财为父、正印为母；女命正财为父、偏印为母
父母性格/事业/健康/缘分深浅/沟通模式/原生家庭格局

### 【模块十二：子女六亲解析】（宫星同参）

男命官杀为子女；女命食伤为子女
子女星旺衰明暗 / 子女性格天赋 / 亲子关系 / 生育时机建议

### 【模块十三：命局格局深度复盘】（高阶升华）

**1. 格局深度拆解**（成败/通关救应/破格关键点/核心做功方式）
**2. 高阶心性复盘**（命运底层性格根源/内耗本质/天赋短板根源）
**3. 人事终极规律**（求财/事业/感情/人际核心运行规律/趋吉避凶心法）

### 统一输出硬性规则（必须遵守）

1. **顺序固定**：13个模块顺序永不调换
2. **先吉后凶**：先讲优势天赋，再讲短板隐患
3. **宫星同参**：六亲/婚姻/财运必须星+宫同看
4. **理论落地**：每个命理组合对应现实人、事、物
5. **主次分明**：核心组合重点详写，次要组合简略带过
6. **逻辑闭环**：旺衰→喜忌→性格→事业→运势→建议全程统一

## Execution（执行步骤）

1. **接收用户输入**：解析性别+出生时间（阳历/阴历+年月日+时辰）
2. **排四柱**：调用 `paipan-jichu` → 输出年柱、月柱、日柱、时柱
3. **藏干+十神**：调用 `paipan-jichu` → 输出地支藏干、天干十神
4. **原局组合分析**：依次调用 `tiangan-wuhe` → `dizhi-liuhe` → `dizhi-liuchong` → `dizhi-liuchuan` → `dizhi-xiangxing` → `dizhi-sanhe/sanhui/banhe`
5. **旺衰+格局+喜忌**：调用 `shengshuai-panbie` → `geshi-dingxing` → `xi-ji-quyong`
6. **十二长生**：调用 `shier-changsheng` → 逐柱分析 + 汇总
7. **大运**：调用 `dayun-fenxi`
8. **汇总13模块**：按【八字完整推盘输出通用规范】固定格式输出

## Boundary（边界）

- 本 skill 是总调度，不单独输出任何分析结论，只负责调用顺序和格式控制
- 所有实质性分析结论由子 skill 输出
- 若子 skill 分析结果互相矛盾，以旺衰喜忌（`shengshuai-panbie` + `xi-ji-quyong`）的结论为准
