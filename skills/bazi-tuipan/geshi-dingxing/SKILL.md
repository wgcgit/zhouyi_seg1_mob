# geshi-dingxing — 格局定性

## Interpretation（核心方法论）

以月令提纲定格局。月令是月支，代表天时，是旺衰判断的核心，也是格局分类的基础。

### 格局总表

| 格局 | 月令 | 喜忌 | 核心象义 |
|---|---|---|---|
| 财格 | 月支为财 | 身旺财旺，身弱财多身弱 | 务实求财，实业贸易 |
| 官格 | 月支为官 | 身旺官旺，身弱官杀攻身 | 公职管理，地位名望 |
| 杀格 | 月支为七杀 | 食神制杀/印化 | 压力转化，危中有机 |
| 印格 | 月支为印 | 身旺印多为忌，财破印 | 学识文化，长辈贵人 |
| 食伤格 | 月支为食神伤官 | 身旺泄秀，身弱泄身太过 | 才华输出，技艺变现 |
| 比劫格 | 月支为比肩劫财 | 官杀制比/食伤化泄 | 竞争激烈，合伙事业 |

### 格局成败判断

**成格条件**：
1. 用神有根气（不被冲合损坏）
2. 忌神有制化（被管住不能作乱）
3. 流通有情（五行流转顺畅）

**破格情形**：
1. 用神被冲合损坏
2. 忌神无制化，大肆攻身
3. 五行交战堵塞

### 格局通关

两个十神相克，只要有第三方十神流转五行，很多凶局直接转吉。

| 相克组合 | 通关方案 | 结果 |
|---|---|---|
| 财破印 | 财生官，官生印 | 格局复原 |
| 伤官见官 | 财通关/印制伤 | 格局复成 |
| 杀攻身 | 印化杀 | 化杀为权 |
| 比劫夺财 | 食伤化比劫生财 | 化夺为生 |

## A2（Future Trigger）

用户输入"测一下八字"，此 skill 被调用来确定月令格局，是判断用神忌神前的关键步骤。

---

## Execution（执行步骤）

1. 确定月支（月令）
2. 对照格局总表，定出格局类型（财/官/杀/印/食伤/比劫）
3. 判断用神是否有根气（不被冲合损坏）
4. 判断忌神是否有制化
5. 判断是否破格：若有，找通关救应方案
6. 输出：格局名称 + 成/破 + 核心特点
