# xi-ji-quyong — 喜忌取用

## Interpretation（核心方法论）

取用神是八字分析的核心目标。用神选错，全盘皆错。

### 用神定义

- **第一用神**：解决命局最大失衡点的五行，必须优先
- **第二用神**：辅助第一用神，或解决次要失衡
- **忌神**：加重命局失衡的五行
- **次忌神**：不是最凶，但也不利
- **中性五行**：非喜非忌，随大运转变

### 取用逻辑（三步）

```
第一步：找失衡点
   ↓ 命局哪里最失衡？（财多身弱？杀重身弱？印旺身弱？）
第二步：所需五行
   ↓ 需要什么五行来解决？（水印生身？木比帮身？）
第三步：忌神为凶的原因
   ↓ 为什么这个五行是忌神？（加重失衡/克制用神/损坏根气？）
```

### 典型命局取用

| 命局类型 | 第一用神 | 第二用神 | 忌神 |
|---|---|---|---|
| 财多身弱 | 水（印生身） | 木（比劫帮身） | 土（财星）；火（食伤生财） |
| 官杀攻身 | 水（印化杀） | 木（比劫帮身） | 金（官杀）；土（财生官杀） |
| 印旺身弱 | 木（比劫帮身） | 水（印可泄） | 土（财破印）；金（官杀生印） |
| 食伤泄身 | 水（印制食伤） | 金（印生源） | 木（比劫生食伤）；火（食伤更旺） |
| 身旺财旺 | 财（我克） | 官杀（克身） | 印（生比劫）；比劫（帮身） |

## Execution（执行步骤）

1. 综合旺衰定论（身旺/身弱/从格）
2. 找出命局最大失衡点（最旺五行/最弱五行/被冲合损坏的五行）
3. 确定所需五行（补弱/抑强/通关/护根）
4. 标注第一用神 → 第二用神 → 中性五行 → 次忌神 → 忌神
5. 写明取用逻辑：原局失衡点 + 所需五行作用 + 忌神为凶原因
6. 输出：用神体系完整表
