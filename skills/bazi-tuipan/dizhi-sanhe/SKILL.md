# dizhi-sanhe — 地支三合局

## Interpretation（核心方法论）

三合局 = 长生 + 帝旺 + 墓库，把分散三支抱团汇聚力量。
> 六合 = 二人羁绊；三合 = 多方结盟、团队、圈子、合伙、势力聚拢。

### 四组三合

| 三合 | 化五行 | 长生→帝旺→墓库 | 核心心性 | 核心人事 | 核心财运 |
|---|---|---|---|---|---|
| 申子辰 | 水局 | 申→子→辰 | 思维灵动，直觉强，善变通 | 流动奔波、异地发展、合伙圈子 | 靠智慧信息流通求财，财来快去也快 |
| 亥卯未 | 木局 | 亥→卯→未 | 仁慈心软，重情义，理想主义 | 文化教育、艺术慈善、朋友助力 | 靠技艺脑力人脉求财，长线发展 |
| 寅午戌 | 火局 | 寅→午→戌 | 热情外向，行动力强，爱面子 | 名气传媒、公职文旅、团队造势 | 靠名气口才曝光获利，大起大落 |
| 巳酉丑 | 金局 | 巳→酉→丑 | 讲义气，执行力强，果决 | 金融法律、军警技术、契约合作 | 实业技术求财，重实际利益 |

### 实战要点

1. **三支齐全** = 完整三合；只有两支 = 半三合（力量减半）
2. **冲中神（子午卯酉）直接破局**；冲长生/墓库，局减弱但不完全破
3. **合化成功** = 五行彻底转变；**合而不化** = 合绊纠缠，原五行还在
4. **喜神三合** = 得助力遇贵人；**忌神三合** = 小人抱团，压力加重

### 铁律

> 三合为聚，抱团成势；冲中神则局破。喜用合则众人相助，忌神合则群小来攻。

## A2（Future Trigger）

用户输入"测一下八字"，此 skill 被调用来分析原局是否有三合局，判断成局/破局/半三合状态。

---

## Execution（执行步骤）

1. 找出原局所有三合局（申子辰、亥卯未、寅午戌、巳酉丑）
2. 判断：完整三合/半三合（长生+帝旺或帝旺+墓库）
3. 判断：合化成功/合绊
4. 判断喜忌：喜神三合（吉）/忌神三合（凶）
5. 若有冲中神：判断是否破局
6. 输出每组三合：组合名称 + 状态 + 人事象义 + 破局判断
7. 若无三合，输出"原局地支无完整三合局"
