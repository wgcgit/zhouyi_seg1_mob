## 一、排盘基础（四大规则）

| 规则 | 要点 |
|---|---|
| 年柱 | 以**立春**换年，非正月初一 |
| 月柱 | 以**十二节令**换月，非农历初一 |
| 日柱 | **23点**后算次一日，非午夜12点 |
| 时柱 | 用**真太阳时**，跨时区需校正 |

### 五虎遁（年干→月干）

```
甲己之年丙作首，乙庚之岁戊为头
丙辛必定寻庚起，丁壬壬寅顺水流
戊癸何方发，甲寅之上好追求
```

### 五鼠遁（日干→时干）

```
甲己还加甲（子时=甲子）
乙庚丙作初（子时=丙子）
丙辛从戊起（子时=戊子）
丁壬庚子居（子时=庚子）
戊癸何方发，壬子是真途（子时=壬子）
```

## 二、地支关系总览

| 关系 | 核心象义 | 代表组合 |

## 三、十神体系

十神以**日干**为中心：

| 关系 | 偏（同性） | 正（异性） |
|---|---|---|
| 生我 | 偏印 | 正印 |
| 克我 | 七杀 | 正官 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 同我 | 比肩 | 劫财 |

## 四、旺衰三要素

| 要素 | 权重 | 内容 |
|---|---|---|
| 得令 | **最大** | 月令五行对日主的生克助力 |
| 得地 | 其次 | 地支通根（本气根/中气根/余气根/无根） |
| 得势 | 最后 | 天干印比帮身的配比 |

**综合定论**：身旺/身弱/中和/从格

## 五、格局与喜忌

**格局**：以月令提纲定财格/官格/杀格/印格/食伤格/比劫格

**取用核心**：
- 找失衡点 → 所需五行 → 忌神原因

## 六、大运排法

**顺逆口诀**：阳男阴女顺排，阴男阳女逆排

**起运计算**：三天=一岁，一天=四个月，一时辰=十天
