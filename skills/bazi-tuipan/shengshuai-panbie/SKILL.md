# shengshuai-panbie — 日主旺衰判断

## Interpretation（核心方法论）

旺衰判断三要素：**得令（月令）权重最大**，其次得地（通根），最后得势（天干）。

> 简单判断口诀：**三项占两项，多半身强；只占一项或全无，多半身弱。**

---

### 一、得令（月令，天时）

月令 = 月支，出生节气月份，代表天时。

| 判断 | 条件 | 示例 |
|---|---|---|
| ✅ 得令 | 月令本气和日主同五行，或月令生日主 | 癸水日主，生于亥月/子月 |
| ❌ 失令 | 月令克/泄/耗日主 | 癸水日主，生于巳午月 |

**⚠️ 得令不等于一定身强**：若地支无根、天干全无帮扶，满局克泄，得令也可以身弱。

---

### 二、得地（通根，地利）

地支藏干里有日主五行，叫通根（树根）。

| 根气档次 | 力量 | 示例（癸水日主） |
|---|---|---|
| 本气根 | 最强 | 癸水见亥、子 |
| 中气根 | 中等 | 地支中气藏癸水 |
| 余气根 | 微弱 | 地支余气藏癸水 |
| 无根 | 无 | 地支完全没有日主藏干 |

**重点**：根如果被冲/合化，根直接受伤，力量大打折扣。

---

### 三、得势（天干，人和）

天干透出印星、比肩劫财，叫得势。

**注意**：天干帮扶必须地支有根，力量才落地；地支无根，天干再多印比，属虚帮，力量有限。

---

### 四、综合定论

| 旺衰类型 | 条件 | 喜忌 |
|---|---|---|
| 身强 | 得令 + 有根 + 天干有印比帮 | 喜克泄耗（官杀、食伤、财）；忌印比劫 |
| 身弱 | 失令 + 根少/无根 + 天干印比少 | 喜生扶（印、比劫）；忌财官杀食伤 |
| 中和 | 生扶与克泄耗大体均衡（现实极少） | 随局取用 |
| 从格 | 日主完全无生无根，全局一股旺势 | 顺从旺势，不按普通身强身弱取用 |

## Execution（执行步骤）

1. **得令**：看月令五行对日主的生克助力，判断是否得令
2. **得地**：看地支通根情况（本气根/中气根/余气根/无根），根气是否受损
3. **得势**：看天干印比生扶与财官食伤克泄耗的配比
4. **综合定论**：明确身旺/身弱/中和/从格，说明核心原因
5. **输出**：得令/得地/得势各占几项 → 综合结论 → 初步喜忌方向
