# 八字推盘术语词典

## 排盘类

| 术语 | 定义 |
|---|---|
| 日主/日干 | 日柱天干，代表"我"，八字的中心点 |
| 月令 | 月支，出生节气月份，代表天时，权重最大 |
| 通根 | 地支藏干中有日主五行，如同树根 |
| 本气根 | 地支本气与日主同五行，力量最强 |
| 中气根 | 地支中气藏日主五行，力量中等 |
| 余气根 | 地支余气藏日主五行，力量微弱 |
| 五虎遁 | 年干推月干的口诀 |
| 五鼠遁 | 日干推时干的口诀 |
| 真太阳时 | 按出生地经度校正的地方时间 |

## 十神类

| 术语 | 定义 |
|---|---|
| 正印/偏印 | 生我者，正为异性相生，偏为同性相生 |
| 正官/七杀 | 克我者，正为异性相克，偏为同性相克 |
| 食神/伤官 | 我生者，食为同性相生，伤为异性相生 |
| 正财/偏财 | 我克者，正为异性相克，偏为同性相克 |
| 比肩/劫财 | 同我者，比为同性相同，劫为异性相同 |

## 十二长生类

| 术语 | 定义 |
|---|---|
| 长生 | 万物破土萌芽，气之始生，有源头根基 |
| 沐浴（败地） | 初生稚嫩，根基不稳，气易损耗，桃花之地 |
| 冠带 | 气渐成长，初具形体，力量稳步上升 |
| 临官（禄） | 天干得实根，力量成熟稳固，最扎实旺地 |
| 帝旺（羊刃） | 五行气场达到顶峰，力量极致强盛，物极必反 |
| 衰 | 盛极转衰，元气逐步消退，力量走下坡 |
| 病 | 气机受损，五行暗藏瑕疵，元气有破损 |
| 死 | 旧气数耗尽，旧阶段彻底终结，非死 |
| 墓（库） | 万物归藏封存，五行收纳入库；冲开合闭 |
| 绝 | 旧气完全消散，天干虚浮无根，真空状态 |
| 胎 | 新气机暗中孕育，力量微弱，潜藏未发 |
| 养 | 气血滋养成形，蓄力待发，逐步积蓄力量 |
| 阳干顺行 | 甲丙戊庚壬，十二长生按顺序排 |
| 阴干逆行 | 乙丁己辛癸，十二长生逆序排 |
| 火土同宫 | 戊土随丙火，己土随丁火 |

## 旺衰类

| 术语 | 定义 |
|---|---|
| 身旺 | 得令+有根+天干有印比帮扶 |
| 身弱 | 失令+根少/无根+天干印比少 |
| 中和 | 生扶与克泄耗大体均衡 |
| 从格 | 日主完全无生无根，顺从全局旺势 |
| 得令 | 月令五行对日主是生是扶 |
| 得地 | 地支通根情况 |
| 得势 | 天干印比帮身的配比 |

## 地支关系类

|---|---|

| 六合 | 地支子丑、寅亥、卯戌、辰酉、巳申、午未相合 |
| 六冲 | 地支子午、丑未、寅申、卯酉、辰戌、巳亥相冲 |

| 相刑 | 寅巳申、丑未戌、子卯、辰午酉亥自刑 |
| 三合局 | 长生+帝旺+墓库三方会合（申子辰、亥卯未、寅午戌、巳酉丑） |

| 生合 | 寅亥合、辰酉合，互相滋养 |
| 克合 | 子丑、卯戌、巳申、午未，表面相合内里矛盾 |
