# shishen-jichu — 十神基础速查

## Interpretation（核心方法论）

十神全部以**日干（日主，代表"我"）**为中心产生。五行+阴阳一分，正好出来十个名称。

### 五大基础关系（必背口诀）

> **先定五行生克，再分阴阳异同，十神就出来。**

| 关系 | 同性（阴阳相同→偏） | 异性（阴阳相反→正） |
|---|---|---|
| 生我者 | 偏印（枭神） | 正印 |
| 克我者 | 七杀（偏官） | 正官 |
| 我生者 | 食神 | 伤官 |
| 我克者 | 偏财 | 正财 |
| 同我者 | 比肩 | 劫财 |

**注意：正偏不是好坏，只是阴阳关系，不等于吉凶。**

### 十神对应人事象义

| 十神 | 核心象义 |
|---|---|
| 正印、偏印 | 长辈、学历、证书、母亲、庇护、想法 |
| 正官、七杀 | 事业、工作、压力、约束、官司、丈夫（女命） |
| 食神、伤官 | 才华、表达、欲望、孩子、输出 |
| 正财、偏财 | 钱财、物质、现实、妻子（男命） |
| 比肩、劫财 | 同辈朋友、手足、竞争者、自我力量 |

### 甲木日主举例

| 天干 | 五行关系 | 十神 |
|---|---|---|
| 壬水 | 水生木，同阴阳 | 偏印 |
| 癸水 | 水生木，阴阳异 | 正印 |
| 庚金 | 金克木，同阴阳 | 七杀 |
| 辛金 | 金克木，阴阳异 | 正官 |
| 丙火 | 木生火，同阴阳 | 食神 |
| 丁火 | 木生火，阴阳异 | 伤官 |
| 戊土 | 木克土，同阴阳 | 偏财 |
| 己土 | 木克土，阴阳异 | 正财 |
| 甲木 | 同我，同阴阳 | 比肩 |
| 乙木 | 同我，阴阳异 | 劫财 |

### 地支藏干取十神

地支本身不直接论十神，要看地支藏干。例：寅中藏甲丙戊，这三个藏干分别拿出来和日主对比，得出各自十神。

---

## Execution（执行步骤）

1. 确定日干五行属性
2. 将八字中每个天干（年干/月干/时干）和每个地支藏干与日干比较
3. 先定五行生克关系（生我/克我/我生/我克/同我）
4. 再分阴阳同性（偏）还是异性（正）
5. 输出完整十神表：天干/藏干 → 五行 → 阴阳 → 十神
