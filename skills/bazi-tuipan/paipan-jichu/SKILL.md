# paipan-jichu — 四柱排盘基础

## Interpretation（核心方法论）

八字排盘是整个命理分析的起点。四个天干地支柱，年月日时，每柱各一干一支，共八个字。核心规则：
- **年以立春换**，非正月初一
- **月以十二节令换**（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），非农历初一
- **日柱以23点换日**，非午夜12点
- **时柱用真太阳时**，跨时区需校正

### 五虎遁（年干→月干）

```
甲己之年丙作首 → 乙庚之岁戊为头
丙辛必定寻庚起 → 丁壬壬寅顺水流
戊癸何方发，甲寅之上好追求
```

用法：年干定正月天干，正月地支固定为寅，顺排12宫。

### 五鼠遁（日干→时干）

```
甲己还加甲（子时=甲子）
乙庚丙作初（子时=丙子）
丙辛从戊起（子时=戊子）
丁壬庚子居（子时=庚子）
戊癸何方发，壬子是真途（子时=壬子）
```

用法：日干定子时天干，子时起，顺排12时辰。

## A2（Future Trigger）

用户输入"测一下这个人的八字：女阳历1987年12月6号晚上6:30"或"排一下这个人的八字：女命，庚申年 戊子月 癸未日，庚申时"，此 skill 被调用来获取完整四柱。

---

## Execution（执行步骤）

1. **解析用户输入**：判断性别（乾造/坤造），判断输入为阳历还是阴历
2. **排年柱**：查万年历或用口诀，年干+立春后确定年支
3. **排月柱**：以节令定月支，五虎遁定月干
4. **排日柱**：查万年历（60甲子连续循环，不可口算）
5. **排时柱**：五鼠遁定子时天干，顺排12时辰
6. **写藏干**：按上表填每个地支的藏干
7. **标十神**：以日干为中心，给每个天干（年干/月干/时干）和每个藏干标注十神
8. **输出**：完整四柱 + 藏干表 + 十神表

---

## Boundary（边界）

- 本 skill 只负责排出准确的四柱，不做旺衰判断
- 若用户输入的是已排出八字（如"庚申年戊子月癸未日庚申时"），直接跳到步骤6-8
